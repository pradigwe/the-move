# 🏠 The Move

A move-out planning web app for students and first-time renters to stay organized, track savings, and plan their move with ease.

## Overview

The Move helps simplify the process of moving into a new place by combining checklists, budgeting, and timeline planning into one organized dashboard. It turns a stressful process into manageable steps from early planning to move-in day.

## Features

- Move-out checklist organized by categories (Furniture, Kitchen, Bathroom, etc.)
- Timeline-based move planning (2+ months → move-in day)
- Savings goal tracker with progress updates
- Dashboard with move readiness overview
- Personalized onboarding to generate move estimates
- Activity feed for tracking progress and updates

## Tech Stack

- Next.js
- React
- Tailwind CSS
